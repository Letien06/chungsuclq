# Data Directory

This directory contains:
- `serviceAccountKey.json` — Firebase service account key (DO NOT COMMIT)
- `sieucap5s_cookies.json` — Saved login cookies for sieucap5s (DO NOT COMMIT)

## Setup
1. Download service account key from Firebase Console
2. Place it here as `serviceAccountKey.json`
3. Run `npm run save-cookies` to save sieucap5s login cookies
