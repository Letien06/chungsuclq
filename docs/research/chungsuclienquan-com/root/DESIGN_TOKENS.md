# Design tokens — chungsuclienquan.com/

## Visual language

- Canvas: almost-black charcoal (`#0b0c0f`) with a blurred full-bleed game-art background.
- Surface: dark graphite panels (`#121418` / `#17191f`) with cool gray borders.
- Accent: orange-to-red action gradient; orange is used for active states and prices.
- Supporting colors: cyan/teal for ticket counts and security copy, green for completed states, gold for badges.
- Type: condensed display face for labels/prices; readable sans-serif for form copy.
- Shape: 6–10px radii, thin 1px borders, restrained shadows, orange 3px header rule.

## Responsive values observed

- Desktop content width: approximately 1115px centered in the viewport.
- Desktop body layout: 2fr/1fr content grid with a sticky payment card.
- Mobile: one-column flow; header nav collapses to a hamburger and cards become full-width.
- Safe-area spacing is preserved for floating controls on narrow screens.
