# Interaction patterns

- Header remains visible while scrolling.
- Package cards show selected state and open a mobile-friendly sheet through the existing selector.
- Quantity stepper and quick quantity pills remain keyboard/touch accessible.
- Friend-code bulk mode toggles between one-line input and multi-line textarea.
- Checkout CTA continues to route through Firebase-authenticated order submission.
- Floating support opens the existing guide/support path; scroll-to-top appears after scrolling.
- Reduced-motion media query disables ticker and modal motion for accessibility.
